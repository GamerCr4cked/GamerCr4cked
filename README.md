# GamerCr4cked

Personal multi-page portfolio for GamerCr4cked.

## Stack
- Static HTML
- CSS
- Vanilla JavaScript
- Cloudflare Pages

## Structure
All deployable website files live in `public/`, which is the configured Cloudflare Pages output directory.

- `public/index.html` — Home
- `public/about/` — About
- `public/projects/` — Projects
- `public/skills/` — Skills
- `public/contact/` — Contact
- `public/assets/` — Shared styles, scripts, and favicon

No build command is required.
